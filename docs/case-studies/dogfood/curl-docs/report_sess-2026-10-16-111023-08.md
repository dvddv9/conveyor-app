[RISK_NODES]
- RN-1 (критично): version-gate провал → молчаливая деградация (нет `--no-clobber` на curl < 7.83.0).
- RN-5 (критично): дефолт `--no-clobber` vs resume-пример с `--clobber` — взаимоисключающие режимы без правила приоритета.
- RN-8 (критично): нет контракта exit-кода и семантики partial failure при multi-URL.
- RN-10 (важно, COVE: повышено до критично при `-o` + multi-URL): гонка при параллельной записи в один output path.
- RN-2 (важно): «sane defaults» ломается на resume.
- RN-3 (важно): границы применимости vs прямой curl размыты.
- RN-4 (важно): «simple wrapper» vs version-gated матрица.
- RN-6 (важно): стратегическое избегание контрактов (exit-код, сигналы, partial failure).
- RN-11 (важно): обновление curl = неявный breaking change дефолтов wcurl.
- RN-7, RN-9 (опционально): нагрузка и масштабируемость.

[INTERSECTION_RISKS]
- input_silence × assumption_silence: старая система + большой список URL → дефолты не срабатывают, `--no-clobber` отсутствует → массовая перезапись.
- assumption_silence × consequence_silence: доверие к URL × необратимая перезапись через filename resolver.
- input_silence × consequence_silence: нет exit-кода × partial failure → downstream принимает неполные данные за полные.
- security × concurrency: injection `--output` в одном параллельном вызове перезаписывает файл другого потока.
