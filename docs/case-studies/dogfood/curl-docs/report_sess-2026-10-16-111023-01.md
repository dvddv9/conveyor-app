# curl-config — Спецификация: анализ контракта и пробелов

[ECHO] Man-page `curl-config(1)` — read-only CLI-интроспекция libcurl. 14 документированных опций + 1 недокументированная (`--cc`). Материал — документация, не код. task_type=spec, level=D3.

[ROUTE] stage0 → stage1 (scanner) → stage2 (analyst) → stage4 (synthesizer) → stage5 (transmitter). research_first=false, parallel_stages=false.

[CONCLUSION] Спецификация функционально полна для happy-path, но содержит систематические пробелы контракта: недокументированные exit codes (кроме `--checkfor`), неопределённое поведение при неизвестной опции, неоднозначный формат `--vernum`, недокументированный `--cc` в EXAMPLES, и явное предупреждение о нестабильном порядке вывода при одновременном поощрении построчного парсинга. Признаков сетевого trust boundary не найдено (VERIFY: не проверялось). Признаков стабильности формата между версиями libcurl не найдено (VERIFY: не проверялось).

[RISK_NODES]
- **RN-11 (критично):** Формат `--vernum` (hex, ведущий ноль опционален) и порядок `--feature`/`--protocols` — неявные контракты. Исторический прецедент: `--vernum` сломан в 7.15.0.
- **RN-5 (важно):** Внутреннее противоречие: «initial zero might be omitted» vs пример `070704` с ведущим нулём.
- **RN-2 (важно):** `--cc` используется в EXAMPLES, но отсутствует в OPTIONS.
- **RN-1 (важно):** «do not assume any particular order» vs пример `grep SSL`, поощряющий построчный парсинг.
- **RN-6 (важно):** Систематическое избегание контрактных гарантий (exit codes, unknown options, стабильность вывода, локаль).
- **RN-8 (важно):** Нет поведения при отсутствии libcurl / повреждённом конфиге / отсутствии CA bundle.
- **RN-4 (важно):** Сдвиг тезиса: «information about installation» vs build-time артефакты (`--cc`, `--cflags`, `--libs`).
- **RN-3 (опционально):** Не упомянуты альтернативы (pkg-config, `curl_version_info()`).
- **RN-7, RN-9, RN-10 (опционально):** Производительность/масштабируемость/конкурентность — нерелевантны для read-only CLI.

- **TB-1 (curl-config → shell/build system):** command injection через неэкранированный вывод `--cflags`/`--libs` (T, важно); подмена бинаря в PATH (S, важно); отсутствие audit log (R, опционально).

- **TB-3 (curl-config → сеть):** не найдено признаков в MATERIAL (VERIFY: не проверялось).

[SILENCE_LAYERS]
- **Input silence:** нет данных о нагрузке, целевых платформах, потребителях.
- **Assumption silence:** предполагается построчный парсинг, но контракт не зафиксирован.
- **Consequence silence:** изменение формата молча ломает парсеры; откат требует синхронного обновления потребителей (необратимо).

[INTERSECTION_RISKS]
- input_silence × assumption_silence: неизвестный набор парсеров + неявный контракт = скрытая хрупкость интеграций.
- assumption_silence × consequence_silence: предположение о стабильности × необратимость поломки = breaking change без миграционного пути.
- input_silence × consequence_silence: нет данных о среде × необратимое раскрытие build-метаданных.
